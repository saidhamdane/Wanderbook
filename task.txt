Project path:
/root/Wanderbook

Important clarification:

The current images in generated Fuerte Experience magazines are DEMO / TEST images.
They are NOT real traveler photos.

Therefore:

- Demo images must always match the company activity 100%.
- Real traveler photos, when available later, must only appear in dedicated customer-memory/gallery pages.

3. Demo mode versus real traveler mode

Implement clear source rules:

Demo mode

When a magazine is generated without real traveler uploads:

- use activity-specific "demoAssets"
- use activity-specific captions
- do not use old generic travel images
- do not use unrelated SerpApi/Google images automatically
- do not use catamarans, dolphins, or boats for buggy activity

Real traveler mode

When real traveler photos exist:

- customer photos can appear only in:
  - "Historia con fotos del viajero"
  - "Tus recuerdos"
  - "Galería del viajero"
- preserve the real photos
- do not force them into cover or company pages unless explicitly selected
- use neutral captions if an image does not visually match the activity
- never caption a boat image as a buggy adventure

Company photos

Company/SerpApi photos may be used only after passing activity keyword filtering.

If they do not match the resolved activity:

- reject them
- store rejection reason in metadata
- use the relevant curated demo asset instead
